Supprimer définitivement mon comptePermanently delete my account

Cette action supprime l'identité de connexion Supabase ainsi que les données web et les copies cloud Windows associées. Elle ne supprime pas automatiquement les exports JSON et les copies enregistrées sur d'autres appareils. Il n'y a pas d'annulation possible.This deletes your Supabase authentication identity and its associated web data and Windows cloud copies. Other devices and exported JSON files may retain copies. This action cannot be undone.
