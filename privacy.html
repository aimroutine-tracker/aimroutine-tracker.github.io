Privacy policyPolitique de confidentialité

Last updated: 4 November 2026 · Project website versionMise à jour : 4 novembre 2026 · Version site vitrine

This policy describes this informational website and the currently planned desktop product. It does not claim that unimplemented integrations are active.

Cette politique décrit ce site de présentation et le produit Windows envisagé. Elle ne prétend pas que des intégrations non développées sont actives.

1. Website data1. Données du site

This static website does not require accounts, collect form submissions, use advertising or install analytics trackers. The optional language preference is stored in your browser's local storage. As host, GitHub Pages may process technical access information under GitHub's own privacy notice.

Ce site statique ne nécessite pas de compte, ne recueille pas de formulaire, n'affiche pas de publicité et n'utilise pas de traceur statistique. Le choix de langue facultatif est mémorisé dans le stockage local du navigateur. L'hébergeur GitHub Pages peut traiter des informations techniques de connexion selon sa propre politique.

GitHub General Privacy Statement

2. Desktop app development2. Développement de l'application

AimRoutine Tracker is in development. The intended architecture stores training routines, exercise results and progress locally by default. Local JSON imports are user-initiated. The website itself has no connection to those local application files.

AimRoutine Tracker est en développement. L'architecture prévue conserve par défaut les routines, résultats et progrès localement. L'import JSON est volontaire. Le site web n'accède pas aux fichiers locaux de l'application.

3. Riot Games integration3. Intégration Riot Games

Official Riot Sign On and VALORANT match-history synchronization are planned features that are not currently enabled. This website does not request Riot passwords, tokens or API keys. If Riot grants access and the integration launches, this policy will be updated to explain the precise data collected, purposes, retention periods and deletion options before any such processing begins.

La connexion officielle Riot Sign On et la synchronisation des parties VALORANT sont prévues, mais non activées. Ce site ne demande aucun mot de passe, token ou clé API Riot. Si les autorisations sont accordées, cette politique sera mise à jour avant le lancement pour détailler les données collectées, finalités, durées de conservation et possibilités de suppression.

4. Your choices4. Vos choix

You can remove the saved language setting in your browser settings. This informational website has no accounts to delete. Future product data management will be explained before a public launch.

Tu peux effacer la préférence de langue depuis les paramètres du navigateur. Ce site n'a aucun compte utilisateur à supprimer. La gestion des données du futur logiciel sera détaillée avant sa publication.

5. Contact5. Contact

The product owner should publish a valid public contact method before launching the application or submitting this site for final production review.

Le responsable du projet devra ajouter un moyen de contact public et valide avant le lancement du logiciel ou l'examen final de production.
