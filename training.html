Démarrage

Premiers pas

Comment sont calculés les conseils ?

Le coach compare uniquement tes résultats d'une même compétence et, si choisi, d'un même logiciel. Il attend au moins quatre séances renseignées pour signaler une tendance. Les niveaux de difficulté et scénarios doivent rester comparables.

Aucune promesse de gain de rang, aucune donnée Riot et aucun calcul caché.

05 / PRIVACY FIRST

Ma progression m'appartient.

Format portable pour une future application Windows

Transfert expérimental de tes données au format JSON documenté. L'import et l'export fonctionnent entre navigateurs web ; l'application Windows n'accepte pas encore ce format automatiquement.

Exporter / importer une sauvegarde

Le JSON contient tes séances, routines favorites et objectif hebdomadaire. L'import conserve les séances existantes et évite les doublons d'identifiant. Les anciennes sauvegardes v1 sont acceptées.

Effacer toutes mes données

Efface les séances et favoris stockés dans ce navigateur. Pense à exporter tes données avant cette action irréversible.
